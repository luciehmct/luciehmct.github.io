    Automated Bioinformatics eDNA Analysis for MinION

    GenoRobotics / Personal

    View repository on GitHub

    Context: As part of the GenoRobotics initiative, this project focuses on biodiversity monitoring in the Udzungwa Mountains (Tanzania). The goal was to develop a fully automated, scalable bioinformatics pipeline capable of processing on-site Oxford Nanopore (MinION) sequencing data. The pipeline identifies amphibian and mammal species (e.g., Leptopelis, Rhynchocyon) by comparing environmental DNA (eDNA) reads against a Sanger reference database.

    My Contributions

    I designed and implemented the end-to-end Python pipeline, transitioning the workflow from manual analysis to a reproducible automated system. My key technical contributions included:

    • Pipeline Architecture: Built a modular, linear workflow integrating standard tools (cutadapt, minimap2, samtools) to process raw FASTQ data through to species matrices.
    • Consensus-Based Validation (Step 5): I introduced a critical validation step that separates "High Abundance" (quantitative) from "True Identity" (qualitative). By generating consensus sequences for high-count targets and re-aligning them to the database, the system prevents false positives caused by PCR bias or sequencing noise.
    • Reproducibility: Packaged all dependencies in a local Conda environment to ensure the pipeline is portable and can run on standard field laptops.

    Results & Analysis

    The automated pipeline achieved 100% concordance in species identification compared to the manual methods used in the original Menegon et al. study. The matrix generation successfully filtered noise (requiring MAPQ > 40) to produce clear abundance signals.

    The consensus validation step proved essential for interpreting results. For example, while Leptopelis CO1 showed very high abundance (27k reads), the validation revealed a low identity match (17.2%), flagging it for manual inspection rather than blind acceptance. Conversely, species like Sorex alpinus were validated with high confidence.

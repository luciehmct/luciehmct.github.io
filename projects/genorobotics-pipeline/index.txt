17:Tc19,<p><strong>Context:</strong> As part of the <a href="https://www.genorobotics.org/" target="_blank" rel="noopener">GenoRobotics</a> initiative, this project focuses on biodiversity monitoring in the Udzungwa Mountains (Tanzania). The goal was to develop a fully automated, scalable bioinformatics pipeline capable of processing on-site Oxford Nanopore (MinION) sequencing data. The pipeline identifies amphibian and mammal species (e.g., <em>Leptopelis</em>, <em>Rhynchocyon</em>) by comparing environmental DNA (eDNA) reads against a Sanger reference database.</p>

<h3>My Contributions</h3>
<p>I designed and implemented the end-to-end Python pipeline, transitioning the workflow from manual analysis to a reproducible automated system. My key technical contributions included:</p>
<ul>
  <li><strong>Pipeline Architecture:</strong> Built a modular, linear workflow integrating standard tools (<code>cutadapt</code>, <code>minimap2</code>, <code>samtools</code>) to process raw FASTQ data through to species matrices.</li>
  <li><strong>Consensus-Based Validation (Step 5):</strong> I introduced a critical validation step that separates "High Abundance" (quantitative) from "True Identity" (qualitative). By generating consensus sequences for high-count targets and re-aligning them to the database, the system prevents false positives caused by PCR bias or sequencing noise.</li>
  <li><strong>Reproducibility:</strong> Packaged all dependencies in a local Conda environment to ensure the pipeline is portable and can run on standard field laptops.</li>
</ul>

<h3>Results &amp; Analysis</h3>
<p>The automated pipeline achieved <strong>100% concordance</strong> in species identification compared to the manual methods used in the original Menegon et al. study. The matrix generation successfully filtered noise (requiring MAPQ &gt; 40) to produce clear abundance signals.</p>
<p>The consensus validation step proved essential for interpreting results. For example, while <em>Leptopelis CO1</em> showed very high abundance (27k reads), the validation revealed a low identity match (17.2%), flagging it for manual inspection rather than blind acceptance. Conversely, species like <em>Sorex alpinus</em> were validated with high confidence.</p>
